Experimental parser and open-source conversion utility utilizing reverse-engineering techniques to bridge OpenStreetMap data with legacy Nissan Connect (LCN2kai) navigation systems.

This project is an independent research initiative created for personal interoperability purposes. It does not contain any proprietary map data, binaries, or copyrighted material belonging to Bosch, Nissan, or HERE.

# Status

Early Research / Proof of Concept

![Stage](https://img.shields.io/badge/stage-early%20research-orange)

![Status](https://img.shields.io/badge/status-proof%20of%20concept-yellow)

This project is currently in an early exploratory and research phase. While it can successfully parse basic geometry, it is not yet production-ready, highly experimental, and there is no guarantee it will ever evolve into a fully functional converter. Use at your own risk!
